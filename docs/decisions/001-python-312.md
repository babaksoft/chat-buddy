# ADR 001: Use Python 3.12

- Status: Accepted
- Date: 2026-09-09

## Context

Chat Buddy needs a supported Python runtime with dependable compatibility across
its web UI, database, LLM, and development tooling dependencies.

## Decision

Use Python 3.12 as the project runtime.

## Consequences

- Packaging, CI, and local development target Python 3.12.
- The project uses a stable ecosystem baseline rather than adopting a newer
  runtime before dependency support is established.

## Alternatives considered

- Python 3.13 or 3.14 — not selected because compatibility across the required
  packages was less established when this decision was made.
